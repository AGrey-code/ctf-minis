      Why this worked, and the fix
      
The code built the query by gluing text together, so your quote changed the query's structure instead of staying as data. The fix is a parameterized query, which keeps input and code separate:

      
// Vulnerable
query = "SELECT * FROM users WHERE username = '" + user + "' AND password = '" + pass + "'"

// Fixed: the database treats values as data only
query = "SELECT * FROM users WHERE username = ? AND password = ?"
db.execute(query, [user, pass])
