Rebuild the Input

Reverse engineering mini-challenge · beginner · about 5 minutes · Python required

Your mission

The C++ program below took a secret flag, scrambled it, and printed a list of numbers. You can't run it backward, but you can read it. Write a Python script that undoes what the program did and recovers the flag.

You need somewhere to run Python. Any online interpreter works, such as the shell at python.org or an online notebook. Nothing to install or download.

The source code

// scramble.cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string flag = "????????";   // the real flag was here
    vector<int> out;

    for (size_t i = 0; i < flag.size(); i++) {
        int c = flag[i];
        c = c ^ (i + 7);
        c = c + (i % 4) * 3;
        out.push_back(c);
    }

    reverse(out.begin(), out.end());

    for (int v : out) {
        cout << v << " ";
    }
    cout << endl;
    return 0;
}

Useful facts: ^ is XOR, % is the remainder after division, and flag[i] gives the character's number (its ASCII code). Characters are numbers underneath, which is why the math works.

Stuck?

Hint 1. Read the loop one line at a time and say what happens to a single character. There are three steps after the loop starts: XOR with a number that depends on i, add a number that depends on i, then (after the loop) reverse the whole list.
Hint 2. To undo a recipe, undo the steps in the opposite order, using opposite operations. Un-reverse the list first, then subtract instead of add, then XOR again (XOR undoes itself). Use i as the position in the un-reversed list, starting at 0.

Last hint: the full solution. Only open this if you have tried the earlier hints. 
nums = [84, 24, 39, 35, 122, 73, 31, 26, 83, 23, 74, 22, 79, 111,
        119, 47, 70, 105, 120, 102, 74, 115, 46, 71, 90, 70, 73, 75,
        70, 97, 71, 116, 66, 121, 122, 85, 95, 68]

nums = nums[::-1]            # undo reverse()

flag = ""
for i, n in enumerate(nums):
    n = n - (i % 4) * 3      # undo the addition
    n = n ^ (i + 7)          # undo the XOR
    flag += chr(n)           # number back to character

print(flag)

Why this worked

You never ran the C++ program. You read it, worked out each step, and rebuilt the input by running the steps backward. That is the core move of reverse engineering. Real programs hide their logic in compiled machine code instead of readable source, and tools like Ghidra turn it back into something you can read, but the thinking is the same.
