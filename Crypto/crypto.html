Stuck?

XOR is a reversible operation. If you XOR the message with the key to scramble it, XORing the result with the same key unscrambles it.
The scrambled message is written in hexadecimal (0-9 and a-f). Many tools need you to convert from hex to raw bytes first. The key is just text.
Try the free tool CyberChef (gchq.github.io/CyberChef). Use the recipe From Hex, then XOR with the key set to type UTF8.
Why this worked

XOR compares two bits and returns 1 only when they differ. Doing it twice with the same value cancels out: (A XOR K) XOR K = A. Here the key was shorter than the message, so it repeated over and over. That is a repeating-key XOR cipher. It is easy to undo when the key is known, and weak even when it is not, since patterns in the message leak through.

The same solve in Python:

ct  = bytes.fromhex(open("xorcipher.txt").read().strip())
key = open("key.txt").read().strip().encode()
print(bytes(b ^ key[i % len(key)] for i, b in enumerate(ct)).decode())
